I built a cards model, then tested it against the market

Predictions published before Matchday 10 · results added after

I built a yellow-card model for the Polish Ekstraklasa.
Then I tested it against the market.
There is no edge.

The model uses the referee assigned to the match and estimates the expected number of yellow cards. For several rounds I checked whether the model could find a gap between its estimate and the bookmaker's line. It couldn't.

Wieczysta Kraków – Wisła Płock

Fri 9 Oct · ref. Bartosz Frankowski

Model3.5 yellow cards
Market (OPTA, yellows only)3.5
Odds1.84 / 1.84

A coin flip. So there is nothing to play here.

The important part is that I am publishing this before the match. After the game I will add the actual number of cards and compare it with the prediction. The result will stay in the repository with its timestamp — no changing the prediction after seeing the result, no fitting the model backwards.

Why publish a model that doesn't beat the market?
Because that is also a result. If the model and the market give the same number, there is no reason to pretend there is an edge.

One match is still one match. The actual number of cards can land well above or below 3.5. The point is not to make the model look good. The point is to find out whether it actually works.

And so far, for this market: no edge.
